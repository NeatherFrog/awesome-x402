# Архитектура и API

`propdesk/market.py` проверяет и создаёт данные; `feeds.py` импортирует необязательную историю Yahoo; `strategies.py` содержит причинные индикаторы; `backtest.py` делает train, walk-forward и holdout; `risk.py` проверяет план сделки; `compliance.py` проверяет непрерывный holdout по loss floors; `payout.py` моделирует первую выплату. `setups.py` строит условный план с ручным контекстом. `scanner.py` выбирает рынок и исследовательский профиль фирмы, сервис выполняет его как фоновую задачу. `store.py` хранит пользовательское состояние в SQLite; `server.py` связывает расчёты с девятью разделами `static/`. `updater.py` и `launch.py` отвечают за совместимые обновления и перезапуск.

Все операции относятся к исследованию или бумажному планированию. Торгового адаптера нет. Сигнал webhook не вызывает ордер; запись дневника не доказывает реальное исполнение.

## Исследование

```json
{
  "source": "demo",
  "symbol": "EURUSD",
  "profile_id": "generic-static",
  "config": {
    "risk_pct": 0.25,
    "account_size": 100000,
    "fee_bps": 0.2,
    "spread_bps": 1,
    "slippage_bps": 0.5,
    "contract_multiplier": 1,
    "max_leverage": 5,
    "train_fraction": 0.6
  }
}
```

Для `source:csv` добавьте `csv_text`. Дополнительный `strategy_ids` ограничивает каталог. Риск измеряется в процентах, вероятности модели выплат — долями от 0 до 1. Неподдержанные метрики, например profit factor без убытков, могут быть `null`; API не выдаёт `NaN` или `Infinity`.

Для Yahoo передайте `{"source":"yahoo","symbol":"EURUSD","interval":"1h","range":"3mo"}`. Отчёт сохраняет `data.input_source:"yahoo"` и `data.provenance`; основной движок принимает нормализованную реальную историю как `data.source:"csv"`/`config.source:"csv"`. При ошибке сети демо не подставляется. Бары имеют UTC open-label и должны уже быть закрыты; внешние quotes не являются брокерскими fills.

## Фоновый автопоиск

Пример `POST /api/scanner/jobs`:

```json
{
  "source": "yahoo",
  "interval": "1h",
  "range": "3mo",
  "config": {"risk_pct": 0.25, "use_market_costs": true}
}
```

`symbols` необязателен; допускается от 1 до 12 тикеров. `source:"reference"` использует встроенные архивы; общий временной диапазон проверяется, несовместимые валюты/периоды исключаются. Default Yahoo-кандидаты: EURUSD, XAUUSD, NAS100, BTCUSD, MES=F, MNQ=F, AAPL, MSFT. Proxy-инструменты раскрываются в provenance.

После HTTP 202 опрашивайте задачу по id. Сервис сохраняет training lock **до holdout**. Глобальный primary выбирается только на train, до трёх рынков проверяются диагностически; провал primary не заменяется победителем другого holdout. Дополнительный 99% описательный bootstrap и минимум 20 сделок ограничивают paper-review, но не доказывают будущий edge.

В `execution_assumptions` видны per-market расходы/размеры: fee/slippage bps за сторону, полный spread, денежная fee per unit, multiplier и quantity step. Это исследовательские предположения. При `use_market_costs:false` используется единая явно заданная модель. Выбор фирмы требует не менее 30 OOS-сделок, свежего пользовательского подтверждения правил и положительного поддержанного EV; `selected_profile_id` может оставаться `null`.

`POST /api/scanner/use` сохраняет выбранный снимок для обзора и сетапов; он не создаёт ордер. Старый архив остаётся старым после переноса. Подробные контракты: [SCANNER.md](SCANNER.md), [FIRM_SELECTION.md](FIRM_SELECTION.md), [SETUPS.md](SETUPS.md).

`POST /api/payout` принимает `strategy_id`, `profile_id`, `config` с `paths`, `risk_pct` и временным горизонтом. Если стратегия не прошла фильтр или данные синтетические, нужна явная опция `allow_illustrative:true`; результат будет учебным. Bootstrap-пути — пересэмплирование одной выборки, а не независимые реальные испытания стратегии.

## Безопасность и эксплуатация

По умолчанию сервер слушает loopback. Это локальный инструмент для одного пользователя, без многопользовательской аутентификации. Не выставляйте весь API в Интернет: при внешнем доступе обязательны HTTPS, аутентификация, авторизация и ограничение частоты запросов на reverse proxy. Для TradingView публикуйте только маршрут webhook с токеном, не дневник и редактор правил.

API изменений принимает JSON и проверяет Origin для браузерных запросов; CORS не включён. Host по умолчанию ограничен локальными именами и адресом сервера. Для защищённого reverse proxy укажите его hostname без порта в `TRADING_ALLOWED_HOSTS`. HTML не содержит внешних CDN или аналитики, CSP ограничивает скрипты своим сервером. SQLite использует параметризованные запросы. Лимит тела — 5 МБ, исследование одновременно одно, размеры расчётов ограничены. Токен webhook сравнивается constant-time и не сохраняется в базе. Это не заменяет отдельный аудит перед внешним развёртыванием.

Локальные процессы не переживают публикацию cloud snapshot. Повторный запуск: перейти в существующий `/workspace/trading`, проверить Python 3.11+, запустить `python3 -m propdesk serve`. Рабочий каталог уже изолирован: новый Git worktree не нужен.
