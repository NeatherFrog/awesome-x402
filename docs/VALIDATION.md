# Проверка версии 0.2.0

Проверено 1 октября 2026 года в текущей cloud-машине: Python 3.12.14, Node 24.19.0 и Chromium. Тесты используют отдельные временные базы и сохраняют пользовательский дневник.

- `python3 -m unittest discover -s tests -q`: **275 тестов, все успешны**, без пропусков. Причинность, train/holdout, издержки, гэпы, стоп/цель, replay лимитов, bootstrap выплат, SQLite, HTTP API, сетапы, фоновые задания, валюты, выбор рынка и защита обновления.
- `python3 scripts/smoke_browser.py`: Chromium прошёл исследование, учебную симуляцию выплат, бумажный чекер, дневник и сохранение после reload, редактор профиля и Pine-скачивание.
- `python3 scripts/smoke_scanner_browser.py`: настоящий расчёт четырёх архивных рынков, фиксация выбора до holdout, расходы по рынкам, открытие отчёта, сохранение задания, блокировка старого сетапа и девять мобильных вкладок без переполнения. Восемь отказов поставщика проверены fixtures: демо вместо настоящих цен не подставляется.
- `python3 scripts/smoke_update_process.py`: изолированный пакет обновлён на следующую **тестовую** версию/commit. Настоящий сервер завершился кодом 42 и перезапустился через лаунчер; health подтвердил новый commit и версию. SQLite и `.env` сохранились, повторное обновление — no-op, собственный процесс остановлен. GitHub transport заменён фиксированными ответами; внешняя доступность этим не подтверждается.
- Распакованный ZIP запускается через Python-лаунчер и получает режим package. В ZIP нет `.git`, `.local`, пользовательских CSV, действующих токенов или окружения. Включены явные публичные архивы с upstream-лицензиями. Детерминированность, SHA-256, манифест и права Unix-лаунчеров проверены.
- Windows timezone fallback проверен при отсутствии системной базы IANA: DST, осенний повтор часа, UTC и bootstrap стандартных профилей. Нативные Windows/macOS-сеансы в этой Linux-машине не запускались.
- `node --check static/app.js`, `python3 -m compileall -q propdesk scripts launch.py` и `git diff --check` прошли.
- `bash scripts/start.sh`, повторный запуск и `python3 scripts/check_ready.py` подтвердили сервер, восемь стратегий, профили, JavaScript, scanner и updater API. Готовность проверяется без внешних запросов и изменения дневника.

Широкий эксперимент проверен текущим движком без новой оптимизации: метрики, сделки, параметры и replay совпали, исходный train-lock сохранён. Остальные архивы воспроизводятся; изменённые данные отклоняются до исследования. GOOG другого периода и BTC quote units не смешиваются с долларовым рейтингом четырёх акций.
Архивы устарели и не подтверждают текущий сетап, выплаты или будущий edge. Автопоиск продолжает исследование на новых данных, сохраняя причины отказа.

## Внешние ограничения

Свежие Yahoo-цены и официальные страницы FTMO/Topstep отклонялись сетевым прокси. Yahoo parser и отказы проверены fixtures; успешная внешняя загрузка здесь не подтверждена. Реальные условия фирм, broker execution и выплаты не проверены; встроенные профили учебные. Новости, настроения и макроцикл задаются вручную с источниками и сроком свежести.
Pine не компилировался в TradingView: локального компилятора нет. Генератор протестирован; экспорт использует базовые параметры и требует проверки в Pine Editor. Публичный HTTPS webhook не развёрнут; локальное хранение авторизованных сигналов проверено, ордера не отправляются.

Cloud `start_skill` и шесть доменов сохранены в черновике, `package_managers` preset сохранён. `install_script` не требуется. Черновик не применяет сеть, не публикует snapshot и не доказывает запуск нового task. Скриншоты — в игнорируемом `artifacts/`.
