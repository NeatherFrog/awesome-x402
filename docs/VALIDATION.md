# Проверка версии 0.3.5

Проверено 1 октября 2026 года в текущей cloud-машине: Python 3.12.14, Node 24.19.0 и Chromium. Тесты используют отдельные временные базы и сохраняют пользовательский дневник.

- `python3 -m unittest discover -s tests -q`: **372 теста, все успешны**, без пропусков в Linux. Причинность, train/holdout, издержки, гэпы, стоп/цель, replay лимитов, bootstrap выплат, SQLite, HTTP API, сетапы, фоновые задания, валюты, выбор рынка и защита обновления. Дополнительно: межпроцессное резервирование запуска автопилота, API календаря, UTC/TTL/недельное покрытие, жизненный цикл фонового обновления и структура Windows-пакета. Закрытие SQLite проверяется с сохранёнными объектами соединений, исключениями транзакции, commit failure, освобождением файлов и 24 параллельными операциями.
- `python3 scripts/smoke_browser.py`: Chromium прошёл исследование, учебную симуляцию выплат, бумажный чекер, дневник и сохранение после reload, редактор профиля и Pine-скачивание.
- `python3 scripts/smoke_scanner_browser.py`: настоящий расчёт четырёх архивных рынков, фиксация выбора до holdout, расходы по рынкам, открытие отчёта, сохранение задания, блокировка старого сетапа и девять мобильных вкладок без переполнения. Восемь отказов поставщика проверены fixtures: демо вместо настоящих цен не подставляется.
- `python3 scripts/smoke_autopilot_browser.py`: реальный временный контроллер/HTTP API/сканер, один запланированный запуск, сохранение после reload, явный повтор, автоматическое отображение только совпадающего primary-отчёта, отказ источника, публичный/ручной календарь, обзор фирм без поддельного подтверждения и мобильная вёрстка. Внешние transport заменены fixtures; startup не отправляет POST или внешние запросы.
- `python3 scripts/smoke_update_process.py`: изолированный пакет обновлён на следующую **тестовую** версию/commit. Настоящий сервер завершился кодом 42 и перезапустился через лаунчер; health подтвердил новый commit и версию. SQLite и `.env` сохранились, повторное обновление — no-op, собственный процесс остановлен. GitHub transport заменён фиксированными ответами; внешняя доступность этим не подтверждается.
- Распакованный ZIP запускается через Python-лаунчер и получает режим package. В ZIP нет `.git`, `.local`, пользовательских CSV, действующих токенов или окружения. Включены явные публичные архивы с upstream-лицензиями. Детерминированность, SHA-256, манифест и права Unix-лаунчеров проверены.
- Windows timezone fallback проверен при отсутствии системной базы IANA: DST, осенний повтор часа, UTC и bootstrap стандартных профилей. На Linux не запускаются Windows/macOS-исполняемые файлы. Windows UTF-8 child arguments и SIGBREAK cleanup проверены регрессиями.
- Native Windows run [0.3.3 / a3206e5](https://github.com/NeatherFrog/awesome-x402/actions/runs/36847268715): **372 теста прошли на Windows**, JavaScript syntax прошёл. Последующие этапы выявили необходимость whole-script PowerShell transport и явного импорта совместимого системного модуля. Проверка подписи не отключена. ## Внешние ограничения

После продолжения сессии 1 октября 2026 Yahoo, GitHub API и официальные FTMO/Topstep страницы стали доступны. Реально получены все восемь рыночных snapshots; источники/UTC/хэши сохранены. Сырые Yahoo snapshots оставлены локально, поскольку разрешение на их перераспространение не установлено; в исходниках — производный отчёт и hash-аудит. Обзор фирм содержит 47 источников и 79 парафраз фактов, не создаёт user_verified и не доказывает текущую ожидаемую прибыль.

Финальная реальная проверка `nfs.faireconomy.media` получила HTTP 200 и 142 строки текущей недели: независимый response SHA-256 совпал с кэшем запущенного фонового worker. [Provenance](news-live-check.json) содержит источник, UTC и хэш. Парсер, кэш, blackout, TTL, автоматический часовой refresh и API проверены fixtures. В запущенном облачном сервере автопилот реально получил все восемь рынков, сохранил tagged primary report и перешёл в completed без выбранного рынка. В клиентском пакете автопилот обновляет календарь, когда источник доступен; sentiment и макроцикл остаются ручными гипотезами. Broker execution и реальные выплаты не проверены; встроенные расчётные профили учебные. Topstep официально запрещает облачную отправку/изменение/relay ордеров.
Pine не компилировался в TradingView: локального компилятора нет. Генератор протестирован; экспорт использует базовые параметры и требует проверки в Pine Editor. Публичный HTTPS webhook не развёрнут; локальное хранение авторизованных сигналов проверено, ордера не отправляются.

Cloud `start_skill` и десять доменов сохранены в черновике, включая официальный Python и календарь; `package_managers` preset сохранён. `install_script` не требуется. Черновик не применяет сеть, не публикует snapshot и не доказывает запуск нового task. Скриншоты — в игнорируемом `artifacts/`.

Windows portability correction: `.gitattributes` keeps byte-pinned CSV/license/source snapshots LF on every Git checkout. A separate temporary checkout with `core.autocrlf=true` reproduced snapshot hash rejection; canonical data stays unchanged. CI uses UTF-8 Python and publishes redacted command diagnostics to GitHub Checks when its log storage is unreachable.
