# Новое исследование текущей истории восьми рынков

**Торговый edge не подтверждён; автоматического допуска к торговле или выбора реальной проп-фирмы нет.** Проверка использует настоящую заново загруженную историю Yahoo, а не демонстрацию или архив 2013–2018. Первичный рынок выбран только на обучении; его финальный результат отрицательный. Положительный результат другого holdout не подменил этот выбор.

Полный отчёт: [current-research.json](current-research.json). Производитель: [scripts/research_current.py](../scripts/research_current.py). Движок отбора: [SCANNER.md](SCANNER.md).

## Заранее зафиксированный эксперимент

До первого запроса цен, **1 октября 2026 в 09:23:08 UTC**, в отчёт записаны восемь тикеров, настройки, модели издержек и хеши исходного кода. SHA-256 протокола: `83108dd796eca702aa0a938ab90211c813055fdd558569ba36a12709b723d0dc`.

Universe фиксирован: **EURUSD, XAUUSD, NAS100, BTCUSD, MES=F, MNQ=F, AAPL, MSFT**. Для каждого запрошен интервал **1h**, период **2y**, через публичный неофициальный Yahoo Chart endpoint. Неуспешный источник записывается как ошибка; дополнительный тикер, синтетическая цена или заполнение пропусков не используются. В этом запуске успешно получены все восемь источников.

Риск — 0,25% на сделку, счёт $100 000, gross leverage максимум 2×. Первые 60% баров каждого рынка используются для выбора из семи фиксированных семейств и существующих двух наборов параметров. Rolling walk-forward целиком находится внутри обучения. Первичный рынок ранжируется только по заранее заданному train score; максимум три рынка получают финальные диагностические результаты. Для допуска необходимы обычные фильтры движка и положительная нижняя граница описательного 99% mean-R интервала, минимум 20 holdout-сделок. Повторного выбора по holdout нет.

Модель правил **общая и иллюстративная**: static total loss 10%, daily loss 5%, target 8%. Это не утверждение о текущем продукте FTMO или любой другой фирмы. Ни одна реальная фирма не рекомендуется на основании generic-профиля.

Целый GC-контракт при этом счёте/риске может оказаться недоступен; скрипт не заменяет его дробью или выдуманным CFD-контрактом. ## Воспроизведение и пределы выводов

```bash
python scripts/research_current.py
```

При существующем завершённом отчёте команда возвращает **этот же frozen результат** без нового запроса цен или нового выбора. Незавершённый протокол не перезаписывается. Для численного воспроизведения используются перечисленные checksum-pinned JSON/CSV, сохранённые `protocol.settings` и неизменный scanner; `on_lock` должен сверить прежний `training_lock_sha256` до holdout. При изменившемся коде источник нового расхождения нужно расследовать, сохраняя первоначальные числа и snapshot. Повторное обращение к текущему Yahoo не воспроизводит прежний эксперимент и требует отдельного протокола.

Эти уже просмотренные holdout нельзя теперь использовать для подбора новых параметров до получения красивой прибыли. Следующая независимая оценка требует заранее выбранного нового периода/источника или будущих paper-наблюдений, а также проверенных правил конкретного продукта и broker execution. Положительная историческая метрика сама по себе не гарантирует прибыль, прохождение challenge или выплату.
