# Trading / PROP LAB

Торговый помощник с главным действием **«Найти сетапы»**: программа сама проверяет рынки, историю стратегий, свежесть цен и ограничения проп-счёта. Версия **0.6.0**, русский интерфейс и обычный браузер. Сервер, расчёты и SQLite используют стандартную библиотеку Python.

На экране «Найти сетапы» показаны допущенные бумажные планы: зона входа, стоп, выход, отмена идеи и причины решения. Технические настройки и ручные бэктесты свёрнуты. Есть автоматический исторический дневник с собственными графиками и ссылками TradingView, отдельный личный журнал и обновление из GitHub. Брокерские ордера не отправляются. Положительный исторический результат не означает подтверждённый будущий edge или выплату.

## Активная цель: 8% в месяц

Новые проверки охватывают сессионные правила индексов, валют и золота,
криптовалютные тренды, относительную стоимость, FVG и направленный поток сделок.
Раздел «Стратегия» автоматически показывает фактически рассчитанные варианты
и сохранённые отчёты. Положительные учебные результаты не открывают доступ
к сигналам: проверка требует расходов, ограничений риска и последующего периода.
Цель пока не подтверждена. [Текущая работа](docs/HIGH_RETURN_CAMPAIGN.md),
[независимый аудит](docs/HIGH_RETURN_RESEARCH_AUDIT.md),
[правила выплат](docs/PROP_PAYOUT_OBJECTIVE.md).

Официальная пятиминутная история сделок и расчётных mark prices проверяется
отдельно. Mark price позволяет оценивать риск, но не является ценой исполнения.
Публичные записи фиксации поставляются с программой; сырые котировки и полные
журналы исследований остаются отдельно. Отсутствие истории явно показано.

## Сохранённая исходная проверка крипторынка

Сначала проведён поиск стратегии; Telegram отложен до подтверждения результата. На главном экране показан статус **«Проверенной стратегии пока нет»**; старые модели свёрнуты в архив. Неудачные исследования сохраняются в отчётах, без торговых уведомлений.

Проверены 208 часовых конфигураций, 64 портфельных и 16 последовательных конструкций funding-хеджа на официальных BTC/ETH данных за январь 2024 — сентябрь 2026. Это варианты и изменения риск-бюджета, а не 288 независимых открытий. Также завершены четыре причинных Liquidity/FVG правила на полном пятиминутном архиве: всего 292 конфигурации.

Одна фиксированная конструкция — полностью оплаченная spot-позиция и равное количество short perpetual, остальной капитал в отдельном залоге — дала **+1,8238% за 2024**, **+0,4833% за 2025**, **+0,1145% за январь–сентябрь 2026** после модельных расходов. Последняя проверка не прошла 99% доверительный интервал и положительность обеих половин периода. Прибыль в сумме не подтверждает стабильную стратегию; допуска к торговле нет. [Полный расчёт](docs/FUNDING_CALIBRATED_RESEARCH.md), [реестр всех проверок](docs/EXPERIMENT_REGISTRY.md), [текущий статус](docs/PROJECT_STATUS.md).

Измерены корреляции дневных результатов, расходы, просадки, стресс-сценарии и блочная неопределённость. Источники/код/выбор зафиксированы SHA-256; новый вариант не заменяет отклонённого победителя после финального результата. Сырые криптоданные не входят в пакет; архив допускает личное исследование без production-исполнения. USDT условно приравнен к USD; точные тарифы, mark prices и будущая прибыль не установлены.

Добавлен устойчивый к перезапускам исследовательский worker через официальный Codex CLI. В этой облачной среде его запуск остановлен до обращения к модели: CLI требует записи в неизменяемый Codex home. Подписка не расходуется этим worker; расход/остаток токенов не выдуманы. [Результат проверки и команды](docs/RESEARCH_RUNNER.md).

## Установка и запуск

Распакуйте готовый ZIP целиком в доступную для записи папку. Windows x64 portable-пакет включает официальный **CPython 3.13.16**; отдельная установка Python для него не нужна. Для macOS, Linux и обычного source ZIP нужен Python **3.11+**. Запуск внутри ZIP не поддерживается.

- Windows: `START-WINDOWS.bat`, который сначала выбирает встроенный `runtime/python.exe`.
- macOS: `START-MAC.command`.
- Linux: `bash START-LINUX.sh`.
- Универсальный запуск: `python3 launch.py` из папки программы.

Лаунчер запускает сервер и открывает браузер после проверки готовности. В установленном пакете ежедневное исследование включено по умолчанию; оно работает, пока программа запущена. Оставьте окно запуска работающим; Ctrl+C завершает программу. При занятом порте он выбирает свободный, сохраняя чужой процесс. Git, Node.js и ключи брокера для обычного запуска не нужны.

Из checkout сервер также запускается напрямую:

```bash
python3 -m propdesk serve --host 127.0.0.1 --port 8000
```

Откройте адрес локального сервера на выбранном порту. Для фоновой разработки: `bash scripts/start.sh`; функциональная готовность: `python3 scripts/check_ready.py`. Можно использовать `make run`. Процессы облачной среды требуется запускать снова после восстановления.

Подробности установки, ZIP и обновлений: [UPDATES.md](docs/UPDATES.md). Отчёт выполненных проверок: [VALIDATION.md](docs/VALIDATION.md).

## Первый сеанс

1. Запустите пакет и нажмите **«Найти сетапы»** на экране «Сегодня». Работа идёт в фоне; доступные рынки и ошибки источников видны в карточках. В установленном пакете есть и автоматическая ежедневная проверка.
2. Получите готовый план либо решение остаться вне рынка с конкретными причинами. Программа не подставляет удачный диагностический результат вместо отклонённого заранее выбранного кандидата. Свежая цена, ограничения счёта и спецификация контракта проверяются отдельно от исторической доходности.
3. Откройте «Дневник» для автоматического разбора последнего завершённого месяца: входы, стопы, причины выхода, затраты и изменение капитала. Выберите дневной тренд SMA10/30 или короткий откат RSI2. Это **историческая симуляция**, а не наши реальные сделки. Личный журнал находится ниже и остаётся отдельным.
4. «Обновления» получает новую опубликованную версию из GitHub и сохраняет пользовательские данные. «Чекер сделки» нужен для актуального состояния вашего счёта. Расширенные настройки и подробные расчёты доступны в свёрнутых инструментах.

Каждая новая фоновая попытка и результаты проверенных семейств сохраняются в локальном реестре `.local/trader/attempts/`; неудачные результаты не удаляются. Опубликованные эксперименты: [дневные источники](docs/SOURCED_RESEARCH.md), [часовые стратегии](docs/INTRADAY_RESEARCH.md), [короткий откат RSI2](docs/MEAN_REVERSION_RESEARCH.md). Дневник: [AUTO_DIARY.md](docs/AUTO_DIARY.md).

Конкретные правила и все сентябрьские сделки: [TRADING_PLAN.md](docs/TRADING_PLAN.md). Практический порядок: [PLAYBOOK.md](docs/PLAYBOOK.md). Правила и экономика: [RULES.md](docs/RULES.md). Формат данных: [DATA.md](docs/DATA.md). API: [ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Автоматический выбор рынка и фирмы

Кнопка «Найти сетапы» обновляет состояние допущенной фиксированной модели и не запускает новый подбор параметров. В версии 0.6 нет модели, прошедшей текущую цель и проверку исполнения: кнопка возвращает пустой список с причиной ожидания. Старый фоновый сканер остаётся отдельным диагностическим инструментом; его положительный результат не открывает уровни на главном экране.

Yahoo-список по умолчанию: EURUSD, XAUUSD, NAS100, BTCUSD, MES=F, MNQ=F, AAPL, MSFT. Ежедневный режим запрашивает **1h/2y**, не более одной автоматической попытки в UTC-день; настройки и отметка попытки переживают перезапуск. Ручное обновление доступно отдельно. При занятом исследовании или обновлении запуск откладывается. Ручной офлайн-скан четырёх архивов AAPL/MSFT/JPM/XOM за 2015–2018 доступен отдельно; при ошибке Yahoo он не подставляется автоматически.

Для каждого рынка применяются видимые **предположения исполнения**: расходы, multiplier, quantity step и плечо. Они не подтверждены как тариф брокера. Целый micro-futures контракт может не поместиться в риск-бюджет — ноль сделок допустим. Для единой модели расходов снимите выбор индивидуальных расходов; зафиксируйте решение до запуска.

Профиль фирмы выбирается по положительному моделируемому EV первой выплаты только для прошедшего первичного рынка и минимум 30 OOS-сделок. Нужны пользовательская проверка правил не старше 90 дней, HTTPS-источник и совместимая валюта. Учебные профили не дают рекомендации реальной фирмы. При неподтверждённых правилах или слабых данных результат — «подходящего кандидата нет».

Официальные сайты FTMO и Topstep удалось прочитать **1 октября 2026**. Обзор содержит источники, timestamps, SHA-256 и различия стадий. Для дальнейшего исследования выделен **FTMO 2-Step Swing** из-за договорного сочетания алгоритмической торговли, удержания позиций и новостей; это условный кандидат по правилам, без рекомендации оплачивать challenge. Прошедшей стратегии и ожидаемой прибыли пока нет. Topstep требует отправлять ордерный поток с личного устройства и запрещает его исполнение/relay через VPS или облако. Подробнее: [PROP_FIRM_REVIEW.md](docs/PROP_FIRM_REVIEW.md), [SCANNER.md](docs/SCANNER.md), [FIRM_SELECTION.md](docs/FIRM_SELECTION.md).

В пакете под лаунчером автопоиск включён при первом запуске, в development checkout — выключен. `TRADING_AUTOPILOT_DEFAULT=0` или `1` меняет только исходное значение; сохранённая настройка имеет приоритет. Результат без прошедшего первичного кандидата сохраняется с отказом, не превращается в разрешённый сетап или ордер.

## Стратегии и проверки

Семь семейств: EMA pullback, Donchian breakout, RSI reversion, Bollinger reversion, trend momentum, inside-bar breakout и volatility expansion. Buy & Hold — ориентир. Это конечный набор гипотез, не «все стратегии на всех активах».

Сигнал вычисляется по закрытой свече, вход — следующий open. ATR-stop и target фиксируются на сигнале. Учтены плечо, quantity step, комиссия, spread, slippage и комиссия на quantity unit. При конфликте stop/target приоритет у стопа; неблагоприятный gap исполняется по open.

Параметры и главный кандидат выбираются на train; walk-forward окна предшествуют финальному holdout. Последняя выборка проверяет исходный выбор. Описательный bootstrap-интервал не исправляет всю неопределённость множественного поиска.

Для профиля правил используется полная непрерывная holdout equity-кривая с adverse OHLC marks. Replay проверяет поддерживаемые loss floors; target/days/consistency выводятся отдельно. Это не многослойное прохождение challenge/funded. Модель первой выплаты отдельно пересэмплирует OOS returns, включает fee попытки, split, consistency, отдельные стадии и наблюдаемую частоту сделок. Её вероятности условны на допущениях, не являются подтверждёнными прогнозами.

## Исследования на реальных данных

Дополнительно проверены фиксированные опубликованные гипотезы на пяти ETF. SMA10/30 дал **+6,88%** за 2017–2023 и **+6,61%** за 2024–сентябрь 2026. Короткий откат RSI2 дал **+2,60%** и **+3,51%**; последняя проверка — 68 сделок, PF 6,38, просадка 0,45%. Это доходности целых периодов, а не годовые. Длинные 99% интервалы включают ноль, а цель даже 8% при данном риске не достигнута; прибыльные бэктесты не подтверждают способ получения выплат. Все три отдельные часовые модели убыточны. Правила, издержки, исходные отказы и происхождение сохранены в связанных выше отчётах.

**1 октября 2026** заново получены все восемь Yahoo-источников: **74 620 закрытых часовых баров за два года**. До holdout зафиксирован первичный кандидат **MES=F / inside-bar breakout**. Его holdout после заявленных расходов: **−1,0178%, 133 сделки**. Все три проверенных кандидата отклонены; положительный альтернативный AAPL не заменил MES. Текущая стратегия и фирма для торговли не выбраны. Протокол, frozen снимки и причины: [CURRENT_RESEARCH.md](docs/CURRENT_RESEARCH.md).

В комплекте доступны четыре дневных архива **AAPL, MSFT, JPM, XOM** и полные отчёты. История заканчивается **7 февраля 2018 года**: это реальные архивные наблюдения, а не сегодняшние сигналы.

Первый эксперимент содержит 28 активных проверок; 23 дали положительный holdout после заданных расходов, **ни одна не прошла все внутренние фильтры**. Train-победители и все отказы сохранены: [RESEARCH_RESULTS.md](docs/RESEARCH_RESULTS.md).

Более широкий поиск проверил обучение на 485 активах того же архива. Shortlist из пяти кандидатов фиксировался на диске до открытия новых holdout; просмотренные четыре тикера исключены, отказ не заменялся другим результатом. **Все пять кандидатов отклонены**: holdout содержит только 11–15 сделок, меньше обязательных 20. Положительная альтернативная строка не переизбирается победителем. Протокол, все исходы и ограничения: [EDGE_SEARCH.md](docs/EDGE_SEARCH.md).

Источник — фиксированный публичный исторический snapshot с SHA-256. Survivorship bias, corporate actions, фактическое исполнение, календарь проп-фирмы и сегодняшние условия полностью не установлены. Положительная строка отчёта не становится подтверждённой выплатной стратегией.

Есть отдельные независимые проверки [GOOG, 2004–2013](docs/INDEPENDENT_RESULTS.md) и [ETH/BTC, 2018](docs/CRYPTO_RESULTS.md). Их периоды и валюты различаются; они не объединяются с USD-архивами в рейтинг текущих рынков. Квалифицированной стратегии эти эксперименты также не установили. Архивы объясняют работу проверки и не являются сегодняшними сетапами.

## Внешние цены и собственный CSV

Yahoo — публичный **неофициальный** исторический feed. Его использует ежедневное исследование и ручные запросы; это не подключение брокера. В ранней проверке proxy возвращал **403**; повторный реальный запуск **1 октября 2026** успешно получил все восемь источников. Доступность другого компьютера и последующих запросов проверяется при запуске.

Перед Yahoo-автопоиском обновляется недельный экономический календарь Forex Factory через Fair Economy Media. Подтверждается только непустой корректный снимок текущей provider-week не старше 6 часов. На финальной проверке **1 октября 2026** endpoint вернул HTTP 200 и 142 строки текущей недели; независимый SHA-256 совпал с реальным кэшем фонового worker. Пока автопилот включён, календарь обновляется отдельно каждый час. Ошибка не заменяется вымышленным расписанием и не разрешает бумажный вход. Ручное обновление календаря доступно отдельно; прогнозы/actual/sentiment из него не используются. Подробнее: [NEWS.md](docs/NEWS.md).

Короткие названия требуют внимания: EURUSD → `EURUSD=X`, BTCUSD → `BTC-USD`, **XAUUSD → futures proxy `GC=F`**, **NAS100 → неторгуемый индекс `^NDX`**. Futures/index feed отличается от spot/CFD проп-счёта. При отказе используйте CSV; синтетические данные не подставляются как реальные. Подробнее: [FEEDS.md](docs/FEEDS.md).

CSV: `time,open,high,low,close,volume`. `time` — UTC open-label (`Z` или `+00:00`), каждый бар уже полностью закрыт. Порядок строго возрастающий без дублей; положительные конечные OHLC с корректной оболочкой. До 30 000 баров; HTTP body до 5 MiB, CLI CSV до 12 MiB; исследованию нужно минимум 300 баров.

Quantity — выбранные units/contracts, не автоматические lots. `contract_multiplier` — деньги счёта за движение цены на 1,0 на единицу quantity. При другой валюте требуется отдельная конвертация. Комиссия и slippage — **bps за сторону**, spread — **полный**; `fee_per_unit` — денежная комиссия на единицу за сторону. Полные определения: [DATA.md](docs/DATA.md).

CLI для разработки из полного Git checkout:

```bash
python3 scripts/test_offline.py
python3 -m propdesk demo --symbol EURUSD --output /tmp/prop-lab-demo.json
python3 -m propdesk validate-csv /path/to/candles.csv
python3 -m propdesk research --symbol YOUR_ASSET --csv /path/to/candles.csv --output /tmp/research.json
```

## Сохранение и обновления

SQLite: `.local/propdesk.sqlite3`, вне Git. Другой каталог задаётся `--data-dir` или `TRADING_DATA_DIR`. Резервную копию делайте при остановленном сервере; при копировании работающей базы нельзя игнорировать WAL. Экспорт CSV журнала не заменяет копию профилей и исследований.

«Обновления» проверяет `NeatherFrog/awesome-x402`, ветку `main`, и устанавливает совместимую опубликованную версию. Старое имя GitHub-репозитория сохранено. ZIP привязан к commit; updater проверяет структуру/манифест, делает backup, сохраняет пользовательское состояние и отказывается затирать изменённые исходники. Автоматический restart работает через лаунчер; при прямом запуске сервера нужен ручной перезапуск. Подробности: [UPDATES.md](docs/UPDATES.md).

## TradingView

Pine v6 экспортируется для семи семейств с **базовыми параметрами каталога**. Выбранные исследованием параметры переносите вручную. Проверьте компиляцию в Pine Editor, данные, commission/slippage, margin, multiplier и шаг quantity. Python-тесты не компилируют Pine; его execution engine отличается.

`POST /api/webhook/tradingview` принимает планировочный JSON с `symbol, side, price, strategy` и token в body либо Bearer header. Без `TRADING_WEBHOOK_TOKEN` маршрут выключен. Принятый сигнал сохраняется и не создаёт ордер. Нужен отдельный публичный HTTPS-вход; приватный локальный адрес TradingView недоступен. TLS-развёртывание не включено.

`.env.example` описывает имена; приложение не загружает `.env` автоматически. Не сохраняйте реальные токены в Git, exports или публичных настройках графика.

## Практические ограничения

Обзор FTMO/Topstep — датированный снимок публичных документов. Он не подтверждает личную доступность продукта, checkout fee, все договорные условия или будущие изменения. Пользовательские attestations автоматически не создаются. Yahoo, календарь и GitHub updater требуют доступной сети; ошибки сохраняются явно.

Нет live broker execution, платёжных операций, всех стратегий/активов, tick/order-book replay, полного funding/swap/borrow учёта и объединённого риска коррелированных позиций. Календарь не доказывает прибыльность новостного фильтра; макроцикл и sentiment не вычисляются автоматически.

Live-адаптер — отдельная задача: конкретная фирма, разрешение на автоматизацию, точные quotes/fills, сверка позиций, лимиты и аварийная остановка. Для текущего кабинета следующий содержательный этап — свежие проверенные данные и последовательный forward paper test.
